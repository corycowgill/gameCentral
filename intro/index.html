<script src="intro/hallucinated-intro.js"></script>

  HallucinatedIntro.play({ sound: true }).then(startGame);

Called with no canvas it builds its own fullscreen black overlay, plays, removes itself, and resolves the promise — so startGame runs on a clean page. Click, tap or any key skips. Honours prefers-reduced-motion by holding the finished logo instead of strobing. Sound is off unless you ask for it, since browsers block autoplay audio without a user gesture.
